# 数据模型

Atlas 将会话持久化为有序的回合与时间线项目。每个时间线项目必须与其操作所属的会话和
回合一致。

## 回合流程

1. `beginTurn` 原子地创建或更新会话、创建回合并保存用户消息。
2. 模型步骤按发生顺序追加助手内容和工具调用。
3. 模型继续执行前，每个持久化工具调用都必须获得结果。
4. 一个回合只能以完成、取消或失败状态终结一次。

## 压缩

压缩检查点保存摘要和最后一个被压缩的时间线序号。模型的活跃上下文从该序号之后开始。
检查点不得拆分 assistant/tool/result 组；超长单回合可以压缩最早的安全前缀，同时保留
最新项目。

## 失败

持久化和用户可见的失败只包含脱敏摘要。Provider 凭据、请求 header、完整请求体与模型
输出不得进入失败消息或结构化日志。
